# Clemo Club dashboard

The Clemo Books subscription dashboard: members, payments, this month's book, profit, gifts and postal labels.

- Live site: served by GitHub Pages from this repository's `main` branch.
- Data: the Clemo Club Supabase project (`config.js`). The key in `config.js` is the public one; members' data is only visible to signed-in staff.
- Add `?demo` to the address to open a demo with sample members.
